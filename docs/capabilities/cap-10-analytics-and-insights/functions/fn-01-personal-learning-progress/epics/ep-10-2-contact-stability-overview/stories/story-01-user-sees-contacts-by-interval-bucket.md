# User Sees Contacts by Interval Bucket

**As a** user, **I can** see a breakdown of my contacts grouped by review interval bucket (< 7 days, 7–30 days, > 30 days), **so that** I know how many names are truly stable versus still being learned.

## Acceptance Criteria

- [ ] A bar or donut chart shows the count and percentage of contacts in each interval bucket
- [ ] The three buckets are: learning (< 7 days), consolidating (7–30 days), stable (> 30 days)
- [ ] Tapping a bucket filters the contact list to show only that bucket's members
- [ ] The chart updates immediately after a quiz session changes any contact's interval
