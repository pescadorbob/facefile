# User Sees Retention vs Contact List Growth

**As a** user, **I can** see how my retention rate has changed as my contact list has grown, **so that** I can understand whether adding more contacts is affecting my ability to remember existing ones.

## Acceptance Criteria

- [ ] A combined chart shows retention rate and contact count plotted on the same time axis
- [ ] The contact count axis is on a secondary Y-axis to avoid scale confusion
- [ ] The chart covers the full history of the user's account, not just the selected window
- [ ] A tooltip on any data point shows the exact retention rate and contact count for that date
