# User Sees Lapse Count for Contact

**As a** user, **I can** see how many times a specific contact has lapsed (been rated "Forgot"), **so that** I know whether to invest in a deeper structural repair of the encoding rather than just more practice.

## Acceptance Criteria

- [ ] The contact detail page shows a "Lapse Count" summary figure alongside other stats
- [ ] A lapse count of 3 or more triggers a suggestion to edit the name image
- [ ] The lapse count includes all historical lapses, not just recent ones
- [ ] The lapse count is reset to 0 if the user re-creates the contact (deletes and re-adds)
