# User Views Full Review History for Contact

**As a** user, **I can** view the complete review history for a specific contact showing dates, ratings, and intervals, **so that** I can see exactly how difficult they've been to learn over time.

## Acceptance Criteria

- [ ] The contact detail page includes a "Review History" section showing all past quiz events
- [ ] Each event shows: date, rating (Forgot/Hard/Good/Easy), and the interval applied after that rating
- [ ] Events are sorted newest-first with pagination if there are more than 50
- [ ] The review history distinguishes in-app quiz events from event-log entries with a source tag
