# Hardest Contacts List Updates After Sessions

**As a** user, **I can** see the hardest contacts list reflect the results of my most recent quiz session, **so that** it always shows current trouble spots rather than stale rankings.

## Acceptance Criteria

- [ ] The ranking is recomputed and the list refreshed after every quiz session completes
- [ ] A contact that was previously in the top 5 and received a "Good" rating may drop in rank
- [ ] The list shows a "Last updated" timestamp so the user knows how fresh the data is
- [ ] If no contacts have ever been missed, the list shows an empty state with encouragement
