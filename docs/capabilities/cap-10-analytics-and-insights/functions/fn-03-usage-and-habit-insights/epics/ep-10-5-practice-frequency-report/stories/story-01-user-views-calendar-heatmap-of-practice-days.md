# User Views Calendar Heatmap of Practice Days

**As a** user, **I can** see a calendar heatmap showing which days I have practiced over the past year, **so that** I can spot consistency gaps in my habit and identify weeks where I fell off track.

## Acceptance Criteria

- [ ] The heatmap shows a 52-week grid with each cell representing a day
- [ ] Days with at least one quiz answer are filled; days without practice are empty
- [ ] Cell color intensity reflects session volume (lighter = fewer answers, darker = more)
- [ ] Hovering or tapping a cell shows the exact date and number of questions answered
