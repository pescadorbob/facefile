# F-8.2: User Management

> Capability: [Administrative and Content Management](../../README.md)

Allow administrators to create, view, update, and deactivate user accounts, so that the system supports multiple users with data separation. Note: the system doesn't use credentials for users. There is switching which user is in context or logged in, but it is done by selecting the user, not with login. Kind of like Netflix profiles.
