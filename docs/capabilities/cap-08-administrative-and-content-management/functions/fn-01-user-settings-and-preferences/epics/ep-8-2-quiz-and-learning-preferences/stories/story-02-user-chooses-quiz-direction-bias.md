# User Chooses Quiz Direction Bias

**As a** user, **I can** configure my quiz sessions to bias toward Face → Name, Name → Face, or stay balanced, **so that** I can focus practice on my weaker retrieval direction.

## Acceptance Criteria

- [ ] A quiz direction preference offers three options: Mixed (default), Face → Name focus, Name → Face focus
- [ ] "Focus" modes apply a 70/30 split toward the selected direction, not 100/0
- [ ] The active preference is shown on the session start screen
- [ ] Changing the preference takes effect on the next session start
