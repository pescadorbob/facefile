# User Sets Max Questions Per Session

**As a** user, **I can** set the maximum number of quiz questions per session, **so that** sessions fit my available time rather than running until all due contacts are exhausted.

## Acceptance Criteria

- [ ] A session length setting accepts an integer between 5 and 50
- [ ] Sessions end after the configured maximum regardless of how many contacts remain due
- [ ] The remaining due count is shown at session end so the user knows there is more to do
- [ ] The default is 10 questions; the user can change it at any time
