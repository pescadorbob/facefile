# User Chooses Notification Channel

**As a** user, **I can** choose to receive reminders by email, push notification, or both, **so that** I stay informed through the channel that works best for my routine.

## Acceptance Criteria

- [ ] Notification settings show toggles for Email and Push, independently controllable
- [ ] Enabling push notification triggers the device/browser permission request if not yet granted
- [ ] If a user enables email notifications, the email on file is shown for confirmation
- [ ] At least one channel must remain active if reminders are enabled — disabling both toggles disables reminders entirely
