# User Sets Reminder Time of Day

**As a** user, **I can** set the time of day I receive review reminders, **so that** they arrive when I'm most likely to act on them rather than at a generic system time.

## Acceptance Criteria

- [ ] A time picker in notification settings allows selection of hour and minute
- [ ] The time is stored and applied in the user's local timezone
- [ ] The change takes effect starting with the next scheduled notification
- [ ] The current configured time is pre-filled in the picker when the user opens settings
