# User Pauses Reminders for Set Period

**As a** user going on vacation or unavailable for a period, **I can** pause all reminders for a set number of days, **so that** I'm not notified when I can't act on the reminders.

## Acceptance Criteria

- [ ] A "Pause reminders" option in settings lets the user enter a number of days (1–30)
- [ ] Reminders are suppressed for the configured duration and automatically resume afterward
- [ ] The active pause and its end date are visible in notification settings
- [ ] Pausing reminders does not alter the SM-2 schedule or create overdue reviews
