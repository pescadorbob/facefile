# User Permanently Deletes Account

**As a** user, **I can** permanently delete my account and all associated data, **so that** I can fully leave the service with no residual data stored.

## Acceptance Criteria

- [ ] A "Delete Account" option is available in account settings, not on the main navigation
- [ ] Deletion removes: the user record, all contacts, all photos, all review history, all palaces, and all notification settings
- [ ] The deletion is processed immediately and cannot be undone
- [ ] The user is logged out and redirected to the public homepage after deletion is confirmed
