# User Updates Display Name and Email

**As a** user, **I can** update my display name and email address at any time, **so that** my account reflects my current identity.

## Acceptance Criteria

- [ ] A profile settings page shows editable display name and email fields
- [ ] Changing the email requires the user to confirm the new address via a verification email before the change is applied
- [ ] The new email must be unique — another account with the same email is rejected with a clear message
- [ ] The display name change is applied immediately with no verification required
