# User Exports Palace Structure

**As a** user, **I can** export my palace definitions and locus assignments along with my contact data, **so that** the spatial organization I've built is preserved outside the app.

## Acceptance Criteria

- [ ] The export file includes all palace names, their loci, and the contact assigned to each locus
- [ ] Palace data is included in the standard export by default — it is not a separate export action
- [ ] The exported palace structure can be re-imported and will recreate palace assignments correctly
- [ ] If a contact has no palace assignment, that field is omitted (not set to null) in the export
