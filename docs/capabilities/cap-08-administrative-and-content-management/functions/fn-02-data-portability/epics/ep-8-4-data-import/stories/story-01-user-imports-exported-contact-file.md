# User Imports Exported Contact File

**As a** user, **I can** import a previously exported FaceFile JSON file to restore my contacts and review history, **so that** I can migrate between accounts or restore from a backup.

## Acceptance Criteria

- [ ] An "Import Data" option is accessible from the account or settings section
- [ ] Only files in the FaceFile export JSON format are accepted — invalid formats show a clear error
- [ ] The import previews the number of contacts and palaces to be imported before finalizing
- [ ] Imported contacts are merged into the existing account without deleting current contacts
