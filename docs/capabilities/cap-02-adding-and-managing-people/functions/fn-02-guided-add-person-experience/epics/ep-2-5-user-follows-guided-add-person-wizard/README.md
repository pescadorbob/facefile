# E-2.5: User Follows Guided Add-Person Wizard

> Capability: [Adding and Managing People](../../../../README.md) - Function: [Guided Add Person Experience](../../README.md)

A five-step wizard that mirrors the structure of the fundamentals tutorial but applied to a real person the user just met. Each step maps to a technique from the tutorial: name entry, name-image creation, palace placement, association-scene creation, and final review.
