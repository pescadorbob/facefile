# E-2.1: User Adds a New Person to Palace During Meeting

> Capability: [Adding and Managing People](../../../../README.md) - Function: [Person and Palace Management](../../README.md)

**As** a user at a meeting
**I want to** quickly add a new person to my palace with their face, name, and location
**So that** I can immediately begin the memory-encoding process

## Acceptance Criteria (epic-level)

1. User can add person via mobile-optimized quick form
2. User can upload or capture a photo of the person's face
3. User can select which locus in their palace to place the person
4. User can enter person's name (first, last, nickname)
5. User can add optional context notes (role, department, how met)
6. Form can be completed in <2 minutes
7. Application timestamps the encounter
