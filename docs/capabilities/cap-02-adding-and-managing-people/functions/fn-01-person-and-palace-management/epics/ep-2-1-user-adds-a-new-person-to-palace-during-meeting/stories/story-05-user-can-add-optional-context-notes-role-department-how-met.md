# User Can Add Optional Context Notes (Role, Department, How Met)

**As a** user adding a new contact, **I can** record role, department, and how-I-met details, **so that** I have richer cues to draw on when studying the person later.

## Acceptance Criteria

- [ ] The form includes three optional text fields: Role, Department, and How We Met
- [ ] All three fields can be left blank without blocking submission
- [ ] Each field accepts up to 200 characters of free-form text
- [ ] The saved notes are visible on the person's detail view
- [ ] Entering text in only some of the three fields saves those values and leaves the others blank — no field defaults to a placeholder value
