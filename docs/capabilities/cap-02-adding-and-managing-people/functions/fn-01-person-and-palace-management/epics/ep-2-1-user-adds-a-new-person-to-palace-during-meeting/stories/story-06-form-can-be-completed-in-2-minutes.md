# Form Can Be Completed in Under 2 Minutes

**As a** user at a meeting, **I can** finish adding a new person in under 2 minutes, **so that** capturing a contact doesn't interrupt the conversation.

## Acceptance Criteria

- [ ] The required path — first name, photo, and locus — requires no more than 5 distinct interactions (taps, typed entries, or selections) to complete
- [ ] No required field is hidden behind a sub-screen or requires navigating away from the form
- [ ] No confirmation dialog or intermediate screen appears between filling the last required field and tapping Save
- [ ] Optional fields (last name, nickname, role, department, how met) are visible but clearly marked as optional so the user knows they can skip them
- [ ] The keyboard does not obscure the Save button when the last text field is active
