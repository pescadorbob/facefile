# User Can Enter Person's Name (First, Last, Nickname)

**As a** user adding a new contact, **I can** enter a first name, last name, and nickname separately, **so that** I can recall how the person is actually addressed.

## Acceptance Criteria

- [ ] The form has three distinct name fields: First Name, Last Name, and Nickname
- [ ] First Name is required; Last Name and Nickname are optional
- [ ] Each name field accepts up to 100 characters
- [ ] Leading and trailing whitespace is trimmed before the contact is saved
- [ ] Submitting with an empty First Name prevents saving and highlights the field as required
- [ ] A contact saved with only a first name displays correctly throughout the app (no empty label or stray punctuation where the last name would appear)
