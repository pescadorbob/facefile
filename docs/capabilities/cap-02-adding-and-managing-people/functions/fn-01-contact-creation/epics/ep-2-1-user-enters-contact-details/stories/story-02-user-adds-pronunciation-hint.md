# User Adds Pronunciation Hint

**As a** user adding a new contact, **I can** enter an optional phonetic pronunciation of their name, **so that** I have a sound-alike anchor to use when creating my name image.

## Acceptance Criteria

- [ ] A pronunciation field appears below the name field and is clearly marked optional
- [ ] The hint is displayed on the contact detail view and during encoding prompts
- [ ] Saving a contact without a pronunciation hint does not produce an error
- [ ] The hint is included in the quiz flow when the user reviews the name image
