# User Adds Context Notes

**As a** user adding a new contact, **I can** write free-form notes about how I know them, **so that** I have relationship context that supports richer encoding.

## Acceptance Criteria

- [ ] A multi-line notes field is available on the contact creation form
- [ ] Notes are saved with the contact and displayed on the detail view
- [ ] Notes are visible during the encoding flow to inform image creation
- [ ] The field accepts at least 500 characters without truncation
