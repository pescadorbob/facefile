# User Enters Full Name

**As a** user adding a new contact, **I can** enter their first and last name, **so that** the contact is identifiable and can be displayed correctly throughout the app.

## Acceptance Criteria

- [ ] The form requires at least a first name before saving
- [ ] Both first and last name fields accept Unicode characters to support international names
- [ ] The full name is displayed on the contact card and in quiz prompts
- [ ] A validation error appears inline if the name field is submitted empty
