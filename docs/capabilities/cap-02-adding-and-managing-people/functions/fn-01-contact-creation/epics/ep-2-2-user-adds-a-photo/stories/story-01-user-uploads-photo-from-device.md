# User Uploads Photo from Device

**As a** user adding a new contact, **I can** upload a photo from my device's file system, **so that** I can attach an existing image without taking a new one.

## Acceptance Criteria

- [ ] A file picker accepts JPEG, PNG, and WEBP formats
- [ ] Files larger than 10 MB are rejected with a clear size limit message
- [ ] The selected photo is shown in a preview before saving
- [ ] Uploading a new photo replaces the previous one without creating orphaned files
