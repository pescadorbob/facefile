# User Takes Photo with Camera

**As a** user adding a new contact, **I can** take a photo using my device camera directly within the app, **so that** I can capture the person's face in the moment without leaving the flow.

## Acceptance Criteria

- [ ] A "Take Photo" button triggers the device camera API
- [ ] The app requests camera permission and shows an explanation if denied
- [ ] The captured photo is shown in a preview before confirming
- [ ] The camera flow works on both mobile and desktop where camera APIs are supported
