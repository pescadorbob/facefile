# User Crops and Confirms Photo

**As a** user who has selected or captured a photo, **I can** crop it to center the face before saving, **so that** the quiz cards consistently show a clear, well-framed face.

## Acceptance Criteria

- [ ] A crop UI appears after photo selection with a fixed square aspect ratio
- [ ] The user can drag and resize the crop region before confirming
- [ ] Confirming the crop saves the cropped image, not the original
- [ ] The user can cancel the crop and re-select a different photo
