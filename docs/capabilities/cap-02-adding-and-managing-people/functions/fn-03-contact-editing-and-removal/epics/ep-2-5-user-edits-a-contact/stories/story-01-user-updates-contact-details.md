# User Updates Contact Details

**As a** user, **I can** edit the name, pronunciation hint, notes, or group membership of an existing contact, **so that** the contact record stays accurate over time.

## Acceptance Criteria

- [ ] An "Edit" action is available from the contact detail view
- [ ] All fields from contact creation are editable in the edit form
- [ ] Saving updates the contact immediately without reloading the page
- [ ] Review history and SM-2 scheduling data are preserved when contact details change
