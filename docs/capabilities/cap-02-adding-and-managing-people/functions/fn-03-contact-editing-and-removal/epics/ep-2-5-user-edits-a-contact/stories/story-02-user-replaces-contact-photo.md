# User Replaces Contact Photo

**As a** user, **I can** replace the photo on an existing contact, **so that** I can update it when I get a better image or the person's appearance has changed.

## Acceptance Criteria

- [ ] A "Replace Photo" option is available from the contact edit view
- [ ] The new photo goes through the same upload, crop, and confirm flow as a new contact
- [ ] The old photo file is deleted from storage when the new one is confirmed
- [ ] The updated photo appears immediately on the contact card and in quiz flows
