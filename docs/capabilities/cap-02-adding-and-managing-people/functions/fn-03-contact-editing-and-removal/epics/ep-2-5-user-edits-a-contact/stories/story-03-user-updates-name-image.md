# User Updates Name Image

**As a** user, **I can** edit the name image or interaction description saved with a contact, **so that** I can strengthen a weak encoding without creating a new contact.

## Acceptance Criteria

- [ ] The name image and interaction description fields are editable from the contact detail view
- [ ] The current image and description are pre-filled so the user can refine rather than rewrite
- [ ] The updated encoding is shown the next time this contact appears in a quiz
- [ ] A timestamp records when the image was last updated so the user can track refinements
