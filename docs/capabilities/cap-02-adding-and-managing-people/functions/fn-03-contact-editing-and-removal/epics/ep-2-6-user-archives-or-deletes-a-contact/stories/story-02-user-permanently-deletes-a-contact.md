# User Permanently Deletes a Contact

**As a** user, **I can** permanently delete a contact and all associated data, **so that** I can fully remove someone I no longer want in the app.

## Acceptance Criteria

- [ ] A "Delete" option is available from the contact detail view, distinct from "Archive"
- [ ] A confirmation dialog lists exactly what will be deleted (photo, review history, name image)
- [ ] Deletion removes the contact record, photo file, and all review history from the database
- [ ] The contact cannot be recovered after deletion — the confirmation makes this explicit
