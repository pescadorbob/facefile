# User Creates a Group

**As a** user, **I can** create a named group (e.g., "Weekly Meeting", "Neighbors"), **so that** I have a container for organizing contacts by context.

## Acceptance Criteria

- [ ] A "New Group" action is accessible from the contacts list
- [ ] Group names must be unique per user and at least 2 characters long
- [ ] The new group appears immediately in the groups list after creation
- [ ] A group can be created with no contacts in it initially
