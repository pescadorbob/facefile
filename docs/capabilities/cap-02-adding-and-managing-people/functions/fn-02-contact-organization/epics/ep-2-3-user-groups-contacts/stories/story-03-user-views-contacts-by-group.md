# User Views Contacts by Group

**As a** user, **I can** browse the contacts list filtered to a single group, **so that** I can see exactly who belongs to a given context without scrolling through everyone.

## Acceptance Criteria

- [ ] Selecting a group from the sidebar or filter bar scopes the contact list to that group
- [ ] The contact count for the selected group is shown in the list header
- [ ] Contacts who belong to multiple groups appear in each group's filtered view
- [ ] An "All Contacts" view resets the filter and shows the full list
