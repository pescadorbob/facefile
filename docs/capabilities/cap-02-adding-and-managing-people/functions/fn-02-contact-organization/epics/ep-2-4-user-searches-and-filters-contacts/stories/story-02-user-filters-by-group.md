# User Filters by Group

**As a** user, **I can** filter the contact list to show only members of a selected group, **so that** I can find contacts by context rather than name.

## Acceptance Criteria

- [ ] A group filter dropdown or sidebar is visible alongside the contacts list
- [ ] Selecting a group immediately narrows the list to that group's members
- [ ] Search and group filter can be combined (search within a group)
- [ ] The active filter is clearly indicated so the user knows they are in a filtered view
