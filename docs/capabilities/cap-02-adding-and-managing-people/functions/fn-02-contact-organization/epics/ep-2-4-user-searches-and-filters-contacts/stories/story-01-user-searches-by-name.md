# User Searches by Name

**As a** user, **I can** type a partial name into a search bar to find matching contacts, **so that** I can locate anyone in my list quickly even as it grows large.

## Acceptance Criteria

- [ ] The search field is accessible at the top of the contacts list
- [ ] Results update live as the user types, filtering by first or last name
- [ ] A "no results" state is shown when no contacts match the query
- [ ] Clearing the search field restores the full contact list
