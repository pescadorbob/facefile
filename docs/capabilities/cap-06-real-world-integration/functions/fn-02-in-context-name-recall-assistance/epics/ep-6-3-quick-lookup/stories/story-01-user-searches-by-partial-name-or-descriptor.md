# User Searches by Partial Name or Descriptor

**As a** user in a real conversation who has drawn a blank, **I can** quickly search for a person by a partial name or a contextual descriptor (e.g., "red hair, marketing"), **so that** I can retrieve their full name discreetly.

## Acceptance Criteria

- [ ] A quick-access search is reachable within 2 taps from any screen
- [ ] Search matches against name, notes, and group membership
- [ ] Results appear within 200ms of typing to feel instantaneous
- [ ] The search view is minimal with no quiz prompts or distracting UI — it is an in-the-moment tool
