# User Views Name Image in Quick-Glance View

**As a** user who has found the contact they were looking for, **I can** see their name image and interaction description in a compact quick-glance view, **so that** I can reconstruct the cue on the spot.

## Acceptance Criteria

- [ ] Tapping a search result opens a minimal card showing: name, photo, name image description, and interaction description
- [ ] The card is designed for quick reading — key information is visible above the fold
- [ ] A "Back to Search" button returns the user to the search results without losing the query
- [ ] The quick-glance view does not log a quiz event or affect SM-2 scheduling
