# User Walks Palace in Locus Order

**As a** user preparing for an event, **I can** view contacts in their palace locus order within the app, **so that** I can mentally rehearse the spatial sequence before arriving.

## Acceptance Criteria

- [ ] A "Walk Palace" mode steps through contacts one at a time, ordered by locus within the palace
- [ ] Each step shows the contact's photo, name, locus label, and interaction description
- [ ] The user can step forward and backward through the palace at their own pace
- [ ] Completing the walk does not trigger a quiz rating or affect SM-2 scheduling
