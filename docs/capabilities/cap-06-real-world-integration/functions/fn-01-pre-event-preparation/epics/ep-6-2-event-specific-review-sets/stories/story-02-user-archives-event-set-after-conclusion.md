# User Archives Event Set After Conclusion

**As a** user whose event has concluded, **I can** archive or dissolve the event review set, **so that** my active lists stay clean without losing the underlying contact data.

## Acceptance Criteria

- [ ] An "Archive Set" action is available from the event set detail view
- [ ] Archiving removes the set from the active list but does not delete its contacts
- [ ] A "Dissolved" or "Archived" section lets users view and restore past event sets
- [ ] Archiving an event set does not alter SM-2 schedules for its member contacts
