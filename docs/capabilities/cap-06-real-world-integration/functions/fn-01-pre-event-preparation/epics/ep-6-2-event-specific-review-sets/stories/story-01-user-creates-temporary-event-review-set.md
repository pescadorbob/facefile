# User Creates Temporary Event Review Set

**As a** user attending a one-time event, **I can** create a temporary review set for it, **so that** I'm not modifying my permanent group structure for a short-term need.

## Acceptance Criteria

- [ ] A "New Event Set" action is distinct from "New Group" and is labeled as temporary
- [ ] Contacts can be added to the event set from the full contact list by selection
- [ ] The event set is available for review and palace-walk modes just like a permanent group
- [ ] Event sets are listed separately from permanent groups so the distinction is visually clear
