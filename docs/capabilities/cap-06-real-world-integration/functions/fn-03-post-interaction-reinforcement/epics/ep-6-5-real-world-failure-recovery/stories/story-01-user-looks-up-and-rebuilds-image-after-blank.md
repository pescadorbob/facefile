# User Looks Up and Rebuilds Image After Blank

**As a** user who blanked on a name during a real conversation, **I can** immediately look up the contact and edit their name image, **so that** I turn the real-world failure into an active repair session.

## Acceptance Criteria

- [ ] Finding a contact via quick lookup shows an "Edit Image" button on the quick-glance card
- [ ] The edit flow is the same inline editor used in post-quiz repair
- [ ] Saving the edit logs a "real-world repair" event in the contact's history
- [ ] The updated image is used in the next quiz session
