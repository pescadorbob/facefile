# User Notes Context in Which They Forgot

**As a** user who blanked on a name in conversation, **I can** note the context in which I forgot (e.g., "saw them out of context", "couldn't see their face clearly"), **so that** I can adjust the encoding to be more context-independent.

## Acceptance Criteria

- [ ] A "Context Note" field is available during real-world failure recovery
- [ ] The note is saved with the repair event in the contact's history
- [ ] The context note is shown alongside the name image on the contact detail view as a reminder
- [ ] The field is optional — saving without a note does not produce an error
