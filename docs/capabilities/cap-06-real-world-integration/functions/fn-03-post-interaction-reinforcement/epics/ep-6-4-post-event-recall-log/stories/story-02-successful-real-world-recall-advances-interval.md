# Successful Real-World Recall Advances Interval

**As a** user who successfully used a name in conversation, **I can** log it as "Easy" so that the contact's review interval advances as if I had aced a quiz, **so that** real-world wins count toward the learning schedule.

## Acceptance Criteria

- [ ] Marking a contact as "remembered" in the post-event log applies an "Easy" rating to their SM-2 record
- [ ] The updated interval is computed and stored the same way as a quiz-based "Easy" rating
- [ ] The contact's next-review date is updated immediately after the log is saved
- [ ] The event log source tag distinguishes this rating from quiz-based ratings in the review history
