# User Logs Post-Event Recall Outcomes

**As a** user after a meeting or event, **I can** log which contacts I remembered and which I forgot, **so that** my real-world performance feeds back into the learning system.

## Acceptance Criteria

- [ ] A "Log Event Outcomes" flow is accessible from the group or event set detail view
- [ ] The flow presents each contact with a simple remembered / forgot toggle
- [ ] Logging "forgot" for a contact triggers the same lapse logic as a "Forgot" quiz rating
- [ ] The logged outcomes appear in the contact's review history with an "Event" source tag
