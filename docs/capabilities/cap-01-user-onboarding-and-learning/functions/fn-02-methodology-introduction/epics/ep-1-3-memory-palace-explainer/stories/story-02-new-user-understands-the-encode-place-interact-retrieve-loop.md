# New User Understands the Encode-Place-Interact-Retrieve Loop

**As a** new user, **I can** see the four-step encode → place → interact → retrieve loop explained before I add my first person, **so that** I know what each part of the app is for.

## Acceptance Criteria

- [ ] Each of the four steps is illustrated with a brief, concrete example
- [ ] The labels used match the terminology used throughout the app UI
- [ ] User can tap through the examples at their own pace
- [ ] The loop is referenced again contextually when the user adds their first contact
