# New User Sees Intro on Why Names Are Hard

**As a** new user, **I can** see a brief introduction explaining that names are arbitrary and that spatial and image encoding is how to make them stick, **so that** I understand the core problem FaceFile solves before I use it.

## Acceptance Criteria

- [ ] Intro screen appears automatically the first time a new user logs in
- [ ] Content explains that names have no inherent meaning to anchor memory to
- [ ] The encode → place → interact → retrieve four-step loop is introduced visually
- [ ] A "Get Started" button advances to the next onboarding step
