# User Sees Plain Language Explanation of Spaced Repetition

**As a** new user, **I can** see a plain-language explanation of spaced repetition, **so that** I understand why review timing matters and why I should not just cram.

## Acceptance Criteria

- [ ] Explanation avoids technical jargon and does not mention "SM-2" by name
- [ ] Content explains that reviewing just before forgetting is more effective than daily re-reading
- [ ] A simple diagram or animation shows interval growth over successful reviews
- [ ] Explanation appears during onboarding before the first scheduled review is set
