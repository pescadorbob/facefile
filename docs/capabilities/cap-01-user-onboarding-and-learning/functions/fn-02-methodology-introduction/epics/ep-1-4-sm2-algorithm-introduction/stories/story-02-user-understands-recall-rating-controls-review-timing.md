# User Understands Recall Rating Controls Review Timing

**As a** new user, **I can** understand that rating my recall as Easy, Hard, or Forgot controls when I will see that person again, **so that** I treat the rating honestly rather than always picking Easy.

## Acceptance Criteria

- [ ] Rating options (Forgot / Hard / Good / Easy) are shown with a one-line consequence for each
- [ ] Example: "Forgot → see them again tomorrow; Easy → see them in 2 weeks"
- [ ] Explanation appears the first time the user reaches a quiz rating screen
- [ ] A "Got it" dismissal saves a flag so the explanation does not repeat
