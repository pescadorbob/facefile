# User Auto-Taken Into Quiz After First Contact

**As a** new user who just added their first contact, **I can** be automatically taken into a one-question quiz, **so that** I experience retrieval practice within the critical 10–60 second encoding window.

## Acceptance Criteria

- [ ] Quiz prompt appears immediately after the contact is saved in guided mode
- [ ] The quiz contains exactly one Face → Name question on the contact just added
- [ ] The user can skip the quiz with a clearly labelled "Skip for now" option
- [ ] SM-2 parameters are initialized after this first attempt regardless of outcome
