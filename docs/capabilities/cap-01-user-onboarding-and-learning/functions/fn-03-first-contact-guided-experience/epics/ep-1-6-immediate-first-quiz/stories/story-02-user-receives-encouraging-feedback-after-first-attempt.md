# User Receives Encouraging Feedback After First Attempt

**As a** new user after my first quiz attempt, **I can** receive encouraging feedback regardless of whether I got it right, **so that** I feel motivated to continue building the habit.

## Acceptance Criteria

- [ ] A correct answer shows a congratulatory message that references the name image used
- [ ] An incorrect answer shows the correct name alongside the name image cue without negative language
- [ ] Neither outcome uses words like "Wrong", "Failed", or "Incorrect"
- [ ] A clear next-step prompt guides the user to add another contact or go to the dashboard
