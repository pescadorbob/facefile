# User Guided Step by Step Through First Add

**As a** new user, **I can** add my first contact through a step-by-step guided flow with inline prompts at each field, **so that** the full process is clear before I do it on my own.

## Acceptance Criteria

- [ ] Guided flow highlights each field in sequence with a tooltip or callout
- [ ] Each prompt explains briefly why the field matters (e.g. notes help build richer cues)
- [ ] The user cannot accidentally skip the name image step in guided mode
- [ ] A progress indicator shows how many steps remain in the flow
