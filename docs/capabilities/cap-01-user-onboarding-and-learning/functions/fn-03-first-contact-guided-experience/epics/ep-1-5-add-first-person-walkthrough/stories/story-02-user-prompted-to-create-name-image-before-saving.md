# User Prompted to Create Name Image Before Saving

**As a** new user adding my first contact, **I can** be prompted to create a name image (e.g. "Ben → bent beam") before saving, **so that** the encoding habit starts immediately with my very first contact.

## Acceptance Criteria

- [ ] Name image prompt appears after the name field is filled, before the Save button is active
- [ ] Prompt offers three technique options (sound-alike, meaning-based, syllable split) as starting points
- [ ] User can type a free-form image description in their own words
- [ ] In guided mode, the Save button remains disabled until the image field contains at least one word
