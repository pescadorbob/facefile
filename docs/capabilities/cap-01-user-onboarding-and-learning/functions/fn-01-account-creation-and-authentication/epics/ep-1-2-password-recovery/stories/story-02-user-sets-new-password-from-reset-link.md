# User Sets New Password from Reset Link

**As a** user with a valid reset link, **I can** set a new password, **so that** my account is secured with credentials I can remember.

## Acceptance Criteria

- [ ] Reset page requires a new password and a confirmation field
- [ ] New password must meet the same strength requirements as registration
- [ ] Successful reset logs the user in and invalidates all other active sessions
- [ ] Expired or already-used links display a clear error with a link to request a new one
