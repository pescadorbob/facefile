# User Requests Password Reset Email

**As a** user who forgot my password, **I can** request a reset email, **so that** I can regain access without creating a new account.

## Acceptance Criteria

- [ ] Password reset form accepts an email address
- [ ] Reset email is sent within 60 seconds
- [ ] Response is identical whether or not the email exists (prevents user enumeration)
- [ ] Reset link expires after 1 hour
