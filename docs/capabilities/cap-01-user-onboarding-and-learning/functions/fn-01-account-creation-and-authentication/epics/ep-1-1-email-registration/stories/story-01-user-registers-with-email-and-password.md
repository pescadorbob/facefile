# User Registers with Email and Password

**As a** new user, **I can** register with an email address and password, **so that** I can access my personal contact list from any device.

## Acceptance Criteria

- [ ] Registration form requires email and password
- [ ] Password must be at least 8 characters with at least one number
- [ ] Duplicate email addresses are rejected with a clear error message
- [ ] Successful registration redirects the user to the onboarding flow
