# Returning User Logs In

**As a** returning user, **I can** log in with my email and password, **so that** I can resume my practice session where I left off.

## Acceptance Criteria

- [ ] Login form accepts email and password
- [ ] Incorrect credentials return a generic error (no user enumeration)
- [ ] Successful login redirects to the review dashboard
- [ ] Session persists across browser refreshes without requiring re-login
