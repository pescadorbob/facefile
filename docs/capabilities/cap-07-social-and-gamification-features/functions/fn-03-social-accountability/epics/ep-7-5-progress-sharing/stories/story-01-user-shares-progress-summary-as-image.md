# User Shares Progress Summary as Image

**As a** user, **I can** generate and share a visual summary of my learning progress (e.g., "47 names learned in 30 days"), **so that** I can celebrate publicly if I choose.

## Acceptance Criteria

- [ ] A "Share Progress" option is available from the analytics or profile section
- [ ] The generated image includes the user's contact count, streak, and retention rate — no contact names or photos
- [ ] The image is exported in a format compatible with standard social sharing (PNG or JPEG)
- [ ] The user must explicitly tap "Share" to export — it is never generated or sent automatically
