# Sharing Is Always Opt-In

**As a** user, **I can** be certain that no sharing action is ever automated or triggered without my explicit input, **so that** my data and learning activity are never shared without my knowledge.

## Acceptance Criteria

- [ ] No sharing action fires without the user tapping a labeled "Share" button
- [ ] Achievement notifications do not auto-post to any platform
- [ ] There is no default-on sharing setting — sharing must be actively enabled by the user
- [ ] The privacy policy reflects that no user data is shared with third parties except through explicit share actions
