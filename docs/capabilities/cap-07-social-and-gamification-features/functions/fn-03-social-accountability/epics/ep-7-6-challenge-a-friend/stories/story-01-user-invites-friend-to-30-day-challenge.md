# User Invites Friend to 30-Day Challenge

**As a** user, **I can** invite a friend to a 30-day name-learning challenge, **so that** we create mutual accountability and both build the habit together.

## Acceptance Criteria

- [ ] A "Challenge a Friend" option generates an invite link or code the user can share
- [ ] The invitee must have (or create) a FaceFile account to join the challenge
- [ ] The challenge starts on the day both parties have accepted and runs for 30 calendar days
- [ ] Both users see the challenge in their active challenges list with the end date shown
