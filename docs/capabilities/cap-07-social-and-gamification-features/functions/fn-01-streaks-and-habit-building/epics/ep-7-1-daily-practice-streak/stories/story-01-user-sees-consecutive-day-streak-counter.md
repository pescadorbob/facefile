# User Sees Consecutive Day Streak Counter

**As a** user, **I can** see a streak counter showing how many consecutive days I've completed at least one review, **so that** daily practice feels tangibly rewarding and worth protecting.

## Acceptance Criteria

- [ ] The streak counter is displayed prominently on the home dashboard
- [ ] A day counts toward the streak only if the user completes at least one quiz answer that day
- [ ] The counter resets to 0 if the user misses a day (unless a streak freeze is applied)
- [ ] The counter shows the current streak and the user's all-time best streak
