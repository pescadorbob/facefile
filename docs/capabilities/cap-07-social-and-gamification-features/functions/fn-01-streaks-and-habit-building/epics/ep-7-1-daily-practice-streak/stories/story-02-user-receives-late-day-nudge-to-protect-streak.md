# User Receives Late-Day Nudge to Protect Streak

**As a** user who hasn't practiced by late afternoon, **I can** receive a gentle in-app nudge reminding me to practice, **so that** my streak is protected and the habit stays consistent.

## Acceptance Criteria

- [ ] A nudge notification is sent if the user has not completed any review by a configurable late-day time (default 5 PM)
- [ ] The nudge message references the current streak so the user knows what's at stake
- [ ] The nudge is not sent if the user has already practiced that day
- [ ] The nudge can be disabled independently of the due-review reminder
