# User Earns Monthly Streak Freeze

**As a** user, **I can** earn one streak-freeze grace day per month, **so that** a single missed day doesn't break a long streak I've worked hard to build.

## Acceptance Criteria

- [ ] One streak freeze is automatically credited to the user's account at the start of each calendar month
- [ ] A freeze is consumed automatically on the first missed day of the month, preserving the streak
- [ ] A notification informs the user that a freeze was used, so they know the streak was protected
- [ ] Unused freezes do not accumulate across months — only one is available at any time
