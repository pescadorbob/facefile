# User Earns First 10 Stable Contacts Achievement

**As a** user, **I can** earn an achievement when I reach a stable review interval (>21 days) on my first 10 contacts, **so that** my early learning progress is celebrated with a concrete milestone.

## Acceptance Criteria

- [ ] The achievement triggers automatically when the 10th contact crosses the 21-day interval threshold
- [ ] A celebratory in-app notification appears with the achievement name and description
- [ ] The achievement is added to the gallery with an earned timestamp
- [ ] The achievement is not retroactively awarded if a previously stable contact later lapses
