# User Earns 30-Day Interval Recall Achievement

**As a** user, **I can** earn an achievement for successfully recalling a contact after a 30-day review interval, **so that** long-term retention — the hardest kind — is specifically rewarded.

## Acceptance Criteria

- [ ] The achievement triggers when the user rates any contact "Good" or "Easy" after an interval of 30 or more days
- [ ] The achievement notification names the contact whose recall triggered it
- [ ] The achievement is awarded once per unique contact who reaches this threshold — adding more contacts can earn the achievement again
- [ ] The interval used for this check is the actual elapsed time since last review, not the scheduled interval
