# User Earns 30-Day Streak Achievement

**As a** user, **I can** earn an achievement for completing 30 consecutive days of practice, **so that** long-term habit formation is recognized and rewarded.

## Acceptance Criteria

- [ ] The achievement triggers on the day the user's streak counter reaches 30
- [ ] A streak freeze day counts toward the 30 days — it is a grace, not a break
- [ ] An in-app notification celebrates the milestone with the specific streak count
- [ ] The achievement is awarded once; completing a second 30-day streak does not re-award it (but could award a higher-tier milestone in a future iteration)
