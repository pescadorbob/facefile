# User Is Prompted to Choose Encoding Technique

**As a** user adding a new contact, **I can** be prompted to pick one of three encoding techniques (sound-alike, meaning-based, or syllable split), **so that** I always have a structured starting point rather than a blank field.

## Acceptance Criteria

- [ ] The encoding prompt appears immediately after the contact's name is entered
- [ ] Three technique options are displayed with a one-line description and example for each
- [ ] Selecting a technique pre-fills the name image field with a starter template
- [ ] The user can switch techniques without losing what they've already typed
