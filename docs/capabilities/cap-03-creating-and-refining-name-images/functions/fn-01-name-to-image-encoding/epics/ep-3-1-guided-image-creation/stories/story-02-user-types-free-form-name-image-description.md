# User Types Free-Form Name Image Description

**As a** user, **I can** type a free-form description of my name image (e.g., "bent beam for Ben"), **so that** my personal encoding is saved with the contact and available during reviews.

## Acceptance Criteria

- [ ] A text field labeled "Name Image" is available on the contact creation and edit forms
- [ ] The field accepts at least 300 characters
- [ ] The saved description is shown on the contact detail page and during quiz flows
- [ ] Saving a contact without a name image is allowed with no error — the field is optional
