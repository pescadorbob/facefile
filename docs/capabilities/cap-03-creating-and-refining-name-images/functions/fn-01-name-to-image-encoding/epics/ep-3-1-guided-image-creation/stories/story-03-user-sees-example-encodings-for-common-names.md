# User Sees Example Encodings for Common Names

**As a** user learning the encoding technique, **I can** see worked examples of name images for common names, **so that** I understand what a strong, vivid encoding looks like.

## Acceptance Criteria

- [ ] A "See Examples" link or section is available near the name image field
- [ ] At least 5 examples are shown, covering sound-alike, meaning-based, and syllable-split techniques
- [ ] Examples include both the name and the full image description, not just the cue word
- [ ] Examples do not auto-fill the user's own field — they are reference material only
