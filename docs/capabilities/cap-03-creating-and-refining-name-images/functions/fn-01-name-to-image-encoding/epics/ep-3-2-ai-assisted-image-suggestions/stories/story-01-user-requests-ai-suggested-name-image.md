# User Requests AI-Suggested Name Image

**As a** user stuck on an unfamiliar name, **I can** request an AI-generated name image suggestion, **so that** I'm never blocked by a name I can't visualize.

## Acceptance Criteria

- [ ] A "Suggest an Image" button is visible near the name image field
- [ ] Clicking it calls the AI suggestion endpoint and shows a loading state
- [ ] The suggestion appears in a preview area, not in the editable field, so the user must actively accept it
- [ ] An error state is shown if the suggestion fails, with an option to retry
