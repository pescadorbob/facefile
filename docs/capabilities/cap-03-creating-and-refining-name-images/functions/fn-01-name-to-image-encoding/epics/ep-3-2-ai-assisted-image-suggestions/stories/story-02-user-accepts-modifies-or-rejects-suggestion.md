# User Accepts, Modifies, or Rejects Suggestion

**As a** user who has received an AI-suggested name image, **I can** accept it as-is, edit it before saving, or dismiss it entirely, **so that** I stay in control of my own encoding.

## Acceptance Criteria

- [ ] Three actions are presented with the suggestion: "Use This", "Edit", and "Dismiss"
- [ ] "Use This" copies the suggestion into the name image field and closes the preview
- [ ] "Edit" copies the suggestion into the editable field with cursor positioned for modification
- [ ] "Dismiss" closes the preview and leaves the field in its prior state
