# User Moves Contact to Different Locus

**As a** user, **I can** reassign a contact to a different locus within the same or a different palace, **so that** I can resolve conflicts or improve my spatial layout.

## Acceptance Criteria

- [ ] The locus and palace fields on the contact edit form are always editable
- [ ] Changing the locus updates the palace view immediately so the old slot is freed
- [ ] No review history is lost when a contact is moved to a new locus
- [ ] The updated locus assignment is reflected in the palace walk view on next load
