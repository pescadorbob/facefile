# User Is Warned of Locus Collision

**As a** user, **I can** receive a warning when I try to assign two contacts to the same locus in the same palace, **so that** spatial collisions don't create confusion during recall.

## Acceptance Criteria

- [ ] A warning appears inline when the selected palace + locus combination is already occupied
- [ ] The warning names the existing contact occupying that locus
- [ ] The user can proceed despite the warning (override is allowed) or pick a different locus
- [ ] The warning does not block saving — it informs, not prevents
