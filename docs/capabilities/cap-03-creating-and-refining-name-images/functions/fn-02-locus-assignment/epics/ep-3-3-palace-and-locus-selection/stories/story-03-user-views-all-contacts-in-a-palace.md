# User Views All Contacts in a Palace

**As a** user, **I can** view all contacts placed within a specific palace, **so that** I can mentally walk through it before an event and rehearse the spatial sequence.

## Acceptance Criteria

- [ ] A palace detail view lists all contacts placed in it, ordered by locus name
- [ ] Each entry shows the contact's name, photo thumbnail, and locus position
- [ ] A "Walk Palace" mode steps through contacts one at a time in locus order
- [ ] An empty palace shows a prompt to add contacts rather than a blank list
