# User Assigns Contact to a Locus

**As a** user, **I can** assign a contact to a specific locus within a palace (e.g., "door", "projector", "window"), **so that** their spatial placement is explicit and reviewable.

## Acceptance Criteria

- [ ] A palace and locus field is available on the contact creation and edit forms
- [ ] The user can type a new locus name or select an existing one used by other contacts in that palace
- [ ] The assigned locus and palace are shown on the contact detail page
- [ ] A contact can only be assigned to one locus per palace at a time
