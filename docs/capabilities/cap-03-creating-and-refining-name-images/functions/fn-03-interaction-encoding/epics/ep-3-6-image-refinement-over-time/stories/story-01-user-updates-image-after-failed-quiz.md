# User Updates Image After Failed Quiz

**As a** user who missed a name during a quiz, **I can** edit my name image or interaction description immediately after the reveal, **so that** I can repair the encoding while the failure context is fresh.

## Acceptance Criteria

- [ ] An "Edit Image" button appears on the post-failure reveal screen
- [ ] Tapping it opens an inline editor pre-filled with the current name image and interaction description
- [ ] Saving the edit stores the new version and dismisses the editor without leaving the quiz
- [ ] The updated image is used in subsequent quiz reviews of the same contact
