# User Flags Image as Weak During Quiz

**As a** user reviewing a contact during a quiz, **I can** flag their name image as "weak" even when I get the answer right, **so that** it surfaces for refinement in a future session before it causes a miss.

## Acceptance Criteria

- [ ] A "Flag as Weak" option is accessible during the quiz reveal (both correct and incorrect outcomes)
- [ ] Flagging adds the contact to a "Needs Work" list visible on the contact list and dashboard
- [ ] The flag is removed automatically when the user updates the name image or interaction description
- [ ] Flagged contacts are given a slight priority boost in session ordering
