# User Writes Interaction Description

**As a** user, **I can** write a brief description of how my name image interacts with the locus (e.g., "Sarah's sari catches on the door handle"), **so that** the elaboration is saved and reviewable during quizzes.

## Acceptance Criteria

- [ ] An "Interaction" text field is available on the contact form, separate from the name image field
- [ ] The field is shown alongside the assigned palace and locus for context
- [ ] The saved interaction description is displayed on the contact detail page
- [ ] The description is shown during quiz review after the user reveals the answer
