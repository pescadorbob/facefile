# User Is Prompted to Include Motion or Emotion

**As a** user writing an interaction description, **I can** receive a prompt reminding me to include motion or emotion in the scene, **so that** the image is vivid enough to survive retrieval.

## Acceptance Criteria

- [ ] A helper tip appears below the interaction field: "Include an action or strong emotion to make the image stickier"
- [ ] The tip is shown only when the field is focused and empty or shorter than 30 characters
- [ ] The tip disappears once the user types a sufficiently long description
- [ ] The tip does not block saving — it is guidance, not validation
