# User Edits Name Image Within Quiz Flow

**As a** user who missed a name, **I can** edit my name image or interaction description directly from the post-failure reveal screen, **so that** I repair the encoding while the failure context is still fresh.

## Acceptance Criteria

- [ ] An "Edit Image" button is visible on the post-failure reveal screen
- [ ] Tapping it opens an inline editor pre-filled with the current name image and interaction description
- [ ] The editor does not navigate away from the quiz — it is an overlay or expandable panel
- [ ] Saving the edit closes the editor and returns the user to the reveal screen with the updated content visible
