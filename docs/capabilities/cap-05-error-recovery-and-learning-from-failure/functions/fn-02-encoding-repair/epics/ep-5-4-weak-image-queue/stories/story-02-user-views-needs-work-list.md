# User Views "Needs Work" List

**As a** user, **I can** view a dedicated list of contacts with the most missed recalls, **so that** I can run a focused repair session targeting my weakest encodings.

## Acceptance Criteria

- [ ] A "Needs Work" section is accessible from the dashboard or contact list
- [ ] Contacts are ranked by number of recent misses, with the most-missed at the top
- [ ] Each entry shows the contact's name, photo, and miss count
- [ ] A "Start Repair Session" button launches a quiz session containing only the listed contacts
