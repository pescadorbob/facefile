# User Sees Saved Name Image After Miss

**As a** user who forgets a name, **I can** see my saved name image and interaction description on the post-failure reveal screen, **so that** I can identify why the encoding failed.

## Acceptance Criteria

- [ ] The reveal screen shows the name image description and interaction description below the name and photo
- [ ] If no name image has been saved, a prompt to add one is shown instead
- [ ] Both fields are readable without tapping — they are not hidden behind a toggle
- [ ] The display of these fields is identical on correct and incorrect reveals
