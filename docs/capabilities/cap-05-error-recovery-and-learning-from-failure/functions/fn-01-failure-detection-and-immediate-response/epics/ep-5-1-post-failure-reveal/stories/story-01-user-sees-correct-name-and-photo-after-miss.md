# User Sees Correct Name and Photo After Miss

**As a** user who forgets a name during a quiz, **I can** immediately see the correct name displayed alongside the contact's photo, **so that** I can reconnect the face and name in one moment.

## Acceptance Criteria

- [ ] The reveal screen shows the contact's full name in large, clear type directly above or below their photo
- [ ] Both name and photo are visible simultaneously without scrolling
- [ ] The reveal appears within 300ms of the user submitting their answer
- [ ] The screen remains visible until the user actively taps "Next" or a rating button
