# User Is Prompted to Reconstruct, Not Re-Read

**As a** user who missed a name, **I can** be prompted to actively reconstruct my encoding rather than simply re-reading it, **so that** the recovery attempt is an active learning event.

## Acceptance Criteria

- [ ] After the reveal, a prompt appears: "Can you picture the scene? Walk through the image before moving on."
- [ ] The prompt is shown for at least 2 seconds before the "Next" button becomes fully active
- [ ] The name image and interaction description remain visible while the prompt is shown
- [ ] The prompt does not force a wait — a user who is ready can tap through immediately
