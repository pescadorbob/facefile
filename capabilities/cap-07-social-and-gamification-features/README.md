# C-7: Social and Gamification Features

Build momentum and habit through streaks, achievements, and optional social accountability — without turning a learning tool into a game that rewards the wrong behaviors.

---

## F-7.1: Streaks and Habit Building

Reward consistent daily practice, not just volume.

### E-7.1.1: Daily Practice Streak
- S-7.1.1.1: As a user, I see a streak counter showing how many consecutive days I've completed at least one review so daily practice feels rewarding
- S-7.1.1.2: As a user, I receive a gentle in-app nudge if I haven't practiced by late afternoon so my streak is protected

### E-7.1.2: Streak Recovery
- S-7.1.2.1: As a user who missed a day, I see how close I was to my streak milestone so the loss feels specific rather than total
- S-7.1.2.2: As a user, I can earn a one-time "streak freeze" grace day per month so a single miss doesn't break long streaks

---

## F-7.2: Achievement System

Recognize meaningful milestones that reflect real learning progress.

### E-7.2.1: Learning Milestones
- S-7.2.1.1: As a user, I earn an achievement when I reach stable recall (interval > 21 days) on my first 10 contacts so progress is celebrated concretely
- S-7.2.1.2: As a user, I earn an achievement for completing 30 consecutive days of practice so long-term habit is recognized
- S-7.2.1.3: As a user, I earn an achievement for successfully recalling someone after a 30-day interval so long-term retention is rewarded

### E-7.2.2: Achievement Gallery
- S-7.2.2.1: As a user, I can view all earned and locked achievements so I have visibility into what milestones exist
- S-7.2.2.2: As a user, locked achievements show a hint of what's required so I have direction without spoilers

---

## F-7.3: Social Accountability (Optional)

Let users opt into lightweight social features that create accountability without pressure.

### E-7.3.1: Progress Sharing
- S-7.3.1.1: As a user, I can share a summary of my learning progress (e.g., "I've learned 47 names in 30 days") as an image so I can celebrate publicly if I choose
- S-7.3.1.2: As a user, sharing is always opt-in and never automated so my data is not shared without explicit action

### E-7.3.2: Challenge a Friend
- S-7.3.2.1: As a user, I can invite a friend to a 30-day name-learning challenge so we create mutual accountability
- S-7.3.2.2: As a user in a challenge, I see only my friend's streak and contact count — not their contact names — so privacy is preserved
