# C-10: Analytics and Insights

Show users how their memory is actually improving over time — and surface what's working versus what needs attention. Learning is more motivating when progress is visible.

---

## F-10.1: Personal Learning Progress

Give users a clear picture of how their overall recall is trending.

### E-10.1.1: Retention Rate Dashboard
- S-10.1.1.1: As a user, I can see my overall retention rate (% of quizzes answered correctly) over the last 7, 30, and 90 days so I understand my trajectory
- S-10.1.1.2: As a user, I can see how my retention rate changes as my contact list grows so I understand whether scale is affecting my performance

### E-10.1.2: Contact Stability Overview
- S-10.1.2.1: As a user, I can see a breakdown of my contacts by review interval bucket (e.g., < 7 days, 7–30 days, > 30 days) so I know how many names are truly stable
- S-10.1.2.2: As a user, I can see the average time it took me to stabilize a new contact so I can set realistic expectations for new additions

---

## F-10.2: Per-Contact Performance

Drill into individual contacts to understand where effort is concentrated.

### E-10.2.1: Contact History View
- S-10.2.1.1: As a user, I can view the full review history for a specific contact (dates, ratings, intervals) so I can see how difficult they've been to learn
- S-10.2.1.2: As a user, I can see how many times I've lapsed on a contact so I know which encodings need structural repair, not just more practice

### E-10.2.2: Hardest Contacts List
- S-10.2.2.1: As a user, I can see a ranked list of my most-missed contacts so I know where to focus encoding repair sessions
- S-10.2.2.2: As a user, the hardest contacts list updates in real time after quiz sessions so it always reflects current trouble spots

---

## F-10.3: Usage and Habit Insights

Help users understand their practice patterns so they can optimize their routine.

### E-10.3.1: Practice Frequency Report
- S-10.3.1.1: As a user, I can see a calendar heatmap of my practice days so I can spot consistency gaps in my habit
- S-10.3.1.2: As a user, I can see the time of day I most often practice so I can confirm whether my reminder timing is well-matched

### E-10.3.2: Backlog Awareness
- S-10.3.2.1: As a user, I can see how many contacts are overdue (past their review date) so I understand the size of my backlog
- S-10.3.2.2: As a user, I can see a projection of upcoming reviews per day over the next two weeks so I can anticipate heavy days and spread the load
