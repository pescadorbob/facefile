# C-1: User Onboarding and Learning

Help new users understand the memory palace methodology and get their first meaningful win — a name they actually remember — within their first session.

---

## F-1.1: Account Creation and Authentication

Getting a user from zero to a working, persistent account.

### E-1.1.1: Email Registration
- S-1.1.1.1: As a new user, I can register with an email and password so I can access my personal contact list
- S-1.1.1.2: As a new user, I receive a verification email so my account is tied to a real address
- S-1.1.1.3: As a returning user, I can log in with my email and password to resume my practice

### E-1.1.2: Password Recovery
- S-1.1.2.1: As a user who forgot my password, I can request a reset email so I can regain access
- S-1.1.2.2: As a user, I can set a new password from a secure reset link so my account is restored

---

## F-1.2: Methodology Introduction

Teach the user the memory palace system so they understand *why* the app works, not just *how* to use it.

### E-1.2.1: Memory Palace Explainer
- S-1.2.1.1: As a new user, I see a brief intro explaining that names are arbitrary and that spatial + image encoding is how to make them stick
- S-1.2.1.2: As a new user, I understand the four-step loop: encode → place → interact → retrieve, before I add my first person

### E-1.2.2: SM-2 Algorithm Introduction
- S-1.2.2.1: As a new user, I see a plain-language explanation of spaced repetition so I understand why review timing matters
- S-1.2.2.2: As a new user, I understand that rating my recall (Easy / Hard / Forgot) controls when I see someone again

---

## F-1.3: First-Contact Guided Experience

Walk the user through their first add-quiz cycle so the workflow becomes intuitive immediately.

### E-1.3.1: Add First Person Walkthrough
- S-1.3.1.1: As a new user, I am guided step-by-step through adding my first contact (name, photo, notes) with inline prompts at each field
- S-1.3.1.2: As a new user, I am prompted to create a name image (e.g., "Ben → bent beam") before saving so the encoding habit starts immediately

### E-1.3.2: Immediate First Quiz
- S-1.3.2.1: As a new user, I am automatically taken into a one-question quiz after adding my first contact so I experience retrieval practice right away
- S-1.3.2.2: As a new user, I receive encouraging feedback after my first quiz attempt regardless of outcome so I feel motivated to continue
