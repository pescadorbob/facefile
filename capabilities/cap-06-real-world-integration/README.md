# C-6: Real-World Integration

Learning names in the app only matters if users can use them in the real world. This capability bridges the gap: preparing before events, supporting in-the-moment recall, and reinforcing memory after face-to-face interactions.

---

## F-6.1: Pre-Event Preparation

Help users review the relevant people before walking into a meeting, party, or networking event.

### E-6.1.1: Group-Filtered Pre-Event Review
- S-6.1.1.1: As a user, I can launch a quick review session filtered to a specific group (e.g., "Weekly Meeting") so I rehearse exactly who I'm about to see
- S-6.1.1.2: As a user, I can mentally "walk" a palace in the app by viewing contacts in their locus order so I rehearse the spatial sequence before arriving

### E-6.1.2: Event-Specific Review Sets
- S-6.1.2.1: As a user, I can create a temporary review set for a one-time event (e.g., a conference) so I'm not modifying my permanent group structure
- S-6.1.2.2: As a user, I can archive or dissolve an event review set after it concludes so my active list stays clean

---

## F-6.2: In-Context Name Recall Assistance

Provide lightweight support when the user is in a real interaction and draws a blank.

### E-6.2.1: Quick Lookup
- S-6.2.1.1: As a user in a conversation, I can quickly search for a person by a partial name or descriptor so I can retrieve their full name discreetly
- S-6.2.1.2: As a user, I can view a contact's name image and interaction description in a quick-glance view so I can reconstruct the cue on the spot

---

## F-6.3: Post-Interaction Reinforcement

Capture the retrieval attempt that happened in the real world and feed it back into the learning system.

### E-6.3.1: Post-Event Recall Log
- S-6.3.1.1: As a user after a meeting, I can log which names I remembered and which I forgot so my real-world performance feeds back into the app
- S-6.3.1.2: As a user, names I successfully used in conversation can be rated as "Easy" so their review interval advances appropriately

### E-6.3.2: Real-World Failure Recovery
- S-6.3.2.1: As a user who blanked on a name during a conversation, I can immediately look them up and rebuild the image so I turn the real-world failure into a repair session
- S-6.3.2.2: As a user, I can note the context in which I forgot (e.g., "saw them out of context") so I can adjust the encoding to be more context-independent
