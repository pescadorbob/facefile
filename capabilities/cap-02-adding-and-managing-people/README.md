# C-2: Adding and Managing People

Give users a fast, frictionless way to capture the people they want to remember — with enough context (face, name, notes, group) to make encoding effective.

---

## F-2.1: Contact Creation

Capturing the core data needed to build a memory: name, face, and personal context.

### E-2.1.1: Manual Contact Entry
- S-2.1.1.1: As a user, I can create a new contact by entering a first and last name so the person is added to my list
- S-2.1.1.2: As a user, I can add free-form personal notes (role, how we met, shared interests) so I have context cues beyond the name
- S-2.1.1.3: As a user, I can save a contact without a photo initially so I'm not blocked by missing assets

### E-2.1.2: Photo Capture and Upload
- S-2.1.2.1: As a user, I can upload a photo from my device when adding a contact so their face is attached to the record
- S-2.1.2.2: As a user, I can take a photo with my device camera directly in the app so I can capture someone in the moment
- S-2.1.2.3: As a user, I can crop and adjust the uploaded photo so the face is prominently centered

---

## F-2.2: Contact Organization

Keeping the contact list navigable as it grows.

### E-2.2.1: Grouping and Tagging
- S-2.2.1.1: As a user, I can assign a contact to a group (e.g., "Work," "Neighbors," "Book Club") so my palace stays socially organized
- S-2.2.1.2: As a user, I can create and rename groups so the organization reflects my actual social contexts
- S-2.2.1.3: As a user, I can assign a contact to multiple groups so people who overlap contexts appear in both

### E-2.2.2: Search and Filter
- S-2.2.2.1: As a user, I can search my contacts by name so I can find someone quickly
- S-2.2.2.2: As a user, I can filter my contact list by group so I only see a relevant subset
- S-2.2.2.3: As a user, I can sort contacts by date added or last reviewed so I can find recently added or neglected people

---

## F-2.3: Contact Editing and Removal

Keeping the contact list accurate over time.

### E-2.3.1: Edit Contact Details
- S-2.3.1.1: As a user, I can edit any field on an existing contact (name, photo, notes, group) so the record stays accurate
- S-2.3.1.2: As a user, I can replace a contact's photo so I can use a better image when one becomes available

### E-2.3.2: Archive and Delete
- S-2.3.2.1: As a user, I can archive a contact so they leave my active review queue without being permanently deleted
- S-2.3.2.2: As a user, I can permanently delete a contact so my list only includes people still relevant to me
- S-2.3.2.3: As a user, I am asked to confirm before deleting so I don't lose a contact by accident
