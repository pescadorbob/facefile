# C-8: Administrative and Content Management

Give users control over their account, data, and preferences — and give administrators the tools to manage the platform.

---

## F-8.1: User Settings and Preferences

Let users tailor the app to their workflow and learning style.

### E-8.1.1: Notification Preferences
- S-8.1.1.1: As a user, I can set the time of day I receive review reminders so they arrive when I'm likely to act on them
- S-8.1.1.2: As a user, I can choose to receive reminders by email, push notification, or both so I stay informed through my preferred channel
- S-8.1.1.3: As a user, I can pause all reminders for a set period (e.g., vacation mode) so I'm not nagged when unavailable

### E-8.1.2: Quiz and Learning Preferences
- S-8.1.2.1: As a user, I can set the maximum number of questions per quiz session so sessions fit my available time
- S-8.1.2.2: As a user, I can choose to bias my sessions toward Face → Name, Name → Face, or mixed so I can focus on my weaker direction
- S-8.1.2.3: As a user, I can enable or disable the immediate post-add quiz so the workflow fits my pace

---

## F-8.2: Data Portability

Let users own their data and move it freely.

### E-8.2.1: Data Export
- S-8.2.1.1: As a user, I can export all my contacts (names, notes, images, review history) as a structured file (CSV or JSON) so I have an offline backup
- S-8.2.1.2: As a user, I can export my palace structure and locus assignments so the spatial organization is preserved outside the app

### E-8.2.2: Data Import
- S-8.2.2.1: As a user, I can import a previously exported file to restore my contacts so I can migrate between accounts or devices
- S-8.2.2.2: As a user, import conflicts (duplicate names) are flagged before finalizing so I don't overwrite good data with stale data

---

## F-8.3: Account Management

Core account hygiene: profile, security, and deletion.

### E-8.3.1: Profile Management
- S-8.3.1.1: As a user, I can update my display name and email address so my account reflects my current identity
- S-8.3.1.2: As a user, I can change my password at any time so I can maintain account security

### E-8.3.2: Account Deletion
- S-8.3.2.1: As a user, I can permanently delete my account and all associated data so I can fully leave the service
- S-8.3.2.2: As a user, I am shown a clear summary of what will be deleted and asked to confirm so the action is fully intentional
